# Daily Routine Dial

朝と夜の習慣をチェックしていくための、iPad 常設向けルーティン管理アプリ。

左にアナログ時計と進捗、右に時刻順のチェックリストという 2 ペイン構成。起床後や帰宅後に
iPad の前へ行き、上から順にタップしていく使い方を想定している。

## 特徴

- 依存ライブラリなし。`index.html` 単体で動作する
- チェック状況は端末の localStorage に保存。日付が変わると自動でリセットされ、履歴は残る
- 継続日数（ストリーク）、本日の達成率、直近 7 日間のグラフ
- 「編集」からタスクの追加・削除・時刻・所要時間・朝夜の変更が可能
- 時間帯でアクセントカラーが変化（朝＝アンバー / 夜＝インディゴ）。ライト・ダーク両対応
- Service Worker によりオフラインでも起動する PWA
- Screen Wake Lock 対応（机に置いたまま画面を点けておける）

## iPad へのインストール

1. Safari で公開 URL を開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから全画面で起動する

## ローカルで動かす

```
python -m http.server 8080 --directory .
```

`http://localhost:8080/` を開く。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（HTML / CSS / JS すべて） |
| `sw.js` | オフライン用 Service Worker |
| `manifest.webmanifest` | PWA マニフェスト |
| `icon-*.png`, `apple-touch-icon.png` | ホーム画面アイコン |

アセットを更新したときは `sw.js` の `CACHE` のバージョン番号を上げること。
